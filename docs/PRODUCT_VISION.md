# 🛠️ IRIS Copilot
# PRODUCT VISION

Version : 1.0

---

# Vision

IRIS Copilot est une plateforme d'assistance intelligente destinée aux consultants HelpDesk d'IRIS IT.

Son objectif n'est pas de remplacer le consultant.

Son objectif est de lui permettre de travailler plus rapidement, avec plus de fiabilité et en s'appuyant sur toute la connaissance accumulée par l'entreprise.

IRIS Copilot doit devenir le compagnon de travail quotidien de chaque consultant.

---

# Mission

Réduire le temps consacré aux tâches répétitives afin que les consultants puissent se concentrer sur les décisions à forte valeur ajoutée.

L'application doit :

- assister ;
- guider ;
- documenter ;
- mémoriser ;
- expliquer.

Jamais décider à la place de l'utilisateur.

---

# Notre philosophie

Nous croyons que :

- l'IA doit augmenter l'humain, pas le remplacer ;
- chaque décision importante doit rester sous contrôle humain ;
- la connaissance métier est un patrimoine qu'il faut capitaliser ;
- un bon outil est un outil simple, fiable et transparent.

# Les problèmes que nous voulons résoudre

Aujourd'hui, un consultant doit :

- lire un mail ;
- identifier le client ;
- retrouver la bonne procédure ;
- comprendre la demande ;
- construire un ticket ;
- vérifier les informations ;
- compléter les commentaires ;
- rechercher des interventions similaires.

Ces tâches sont souvent répétitives et chronophages.

IRIS Copilot vise à réduire cette charge.

# Ce que doit ressentir l'utilisateur

Lorsqu'un consultant ouvre IRIS Copilot, il doit avoir l'impression que :

> *"L'application connaît déjà mon métier et m'aide à travailler plus efficacement."*

Pas :

> *"Je dois apprendre à utiliser un nouvel outil."*

---

# Les principes UX

Chaque écran doit :

- être immédiatement compréhensible ;
- éviter la surcharge d'informations ;
- guider naturellement l'utilisateur ;
- fournir un retour clair sur chaque action.

---

# Les principes IA

L'IA :

✔ explique ;

✔ propose ;

✔ recherche ;

✔ synthétise ;

✔ mémorise.

Elle ne :

✖ invente pas ;

✖ ne décide pas seule ;

✖ ne modifie pas les règles métier.

---

# La mémoire métier

Chaque interaction validée enrichit progressivement la connaissance du système.

La mémoire est composée de :

- tickets validés ;
- corrections utilisateur ;
- documents consultés ;
- procédures utilisées ;
- cas similaires.

Cette mémoire ne remplace jamais les règles métier.

Elle aide à les améliorer.

---

# Les indicateurs de réussite

Le projet sera considéré comme réussi si :

- le temps moyen de traitement diminue ;
- les tickets sont plus homogènes ;
- les erreurs diminuent ;
- les procédures sont retrouvées plus rapidement ;
- les consultants utilisent naturellement l'outil.

---

# Vision à moyen terme

IRIS Copilot devient la plateforme centrale du HelpDesk.

Il accompagne toutes les étapes :

- réception ;
- analyse ;
- documentation ;
- création du ticket ;
- validation ;
- historique ;
- suivi.

---

# Vision à long terme

IRIS Copilot devient une plateforme de connaissance métier.

Elle sait :

- retrouver les procédures ;
- expliquer les décisions ;
- proposer des cas similaires ;
- aider à former les nouveaux consultants ;
- capitaliser plusieurs années d'expérience.

L'objectif n'est pas de remplacer les experts.

L'objectif est de rendre leur expertise accessible à toute l'équipe.

---

# Ce que nous ne voulons pas

Nous ne voulons pas :

- un simple chatbot ;
- une interface complexe ;
- une IA qui invente des réponses ;
- un logiciel difficile à maintenir ;
- une accumulation de scripts sans cohérence.

---

# Les valeurs du projet

**Fiabilité**

Les réponses doivent être cohérentes et vérifiables.

**Transparence**

L'utilisateur doit comprendre pourquoi une réponse est proposée.

**Simplicité**

Chaque fonctionnalité doit être intuitive.

**Capitalisation**

Chaque interaction utile enrichit la mémoire du projet.

**Évolutivité**

Le système doit pouvoir grandir sans remise en cause de son architecture.

---

# Notre ambition

Créer le meilleur assistant HelpDesk interne possible.

Un outil capable d'accompagner les consultants au quotidien, de préserver la connaissance métier de l'entreprise et de faire gagner du temps sans jamais sacrifier la qualité.

---

# Notre devise

> **"Transformer l'expérience métier en intelligence collective, grâce à une IA fiable, transparente et centrée sur l'humain."**
